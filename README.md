# Bewerbungs-Tracker

Programm zur Verwaltung meiner Bewerbungen für die Praktikumssuche.

Status: in Planung

## Geplante Funktionen
- Bewerbung erfassen: Firma, Stelle, Ort, Datum, Ansprechpartner
- Status verwalten: offen / Vorstellungsgespräch / Absage / Zusage
- Notizen pro Bewerbung

## Technik
Wird im Rahmen der Umschulung zum Fachinformatiker für Anwendungsentwicklung umgesetzt.
